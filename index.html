PubMed to COA

Build a co-author list for the NSF Collaborators and Other Affiliations template (Table 4) or the USDA NIFA Conflict of Interest List, from a PubMed query. Everything runs in this browser tab: Python compiled to WebAssembly (Pyodide) parses the PubMed records; nothing is sent to any server except NCBI and, only if you ask for it, the AI provider you choose.

Safe use of an API key in a browser page


    
  
  • This page is static. There is no backend, so the key never touches a server other than the provider's API. You can verify this in the browser's network panel, and the Content-Security-Policy in the page source limits where the page may connect.
    • 
  
  • Create a separate key for this tool, set a monthly spending limit on it in the provider's console, and revoke it when you are done.
    • 
  
  • Leave "remember key" off on shared computers. With it on, the key is stored in localStorage for this site only.
    • 
  
  • Review the merges list. The model decides which name variants are the same person; the page never deletes a row the model did not account for, but a wrong merge is still possible.
    • 
  
  • The same cleanup is available offline in the command-line version, which uses your existing ANTHROPIC_API_KEY, ant auth login profile, or OPENAI_API_KEY.
    •
